# air-canvas-video-meeting
Air Canvas Video Meeting: Real-time video calls with gesture-controlled drawing. Users draw/erase/clear canvas using hand gestures (1 finger=draw, 2=erase, fist=clear). Built with MediaPipe hand tracking, KNN classifier, WebRTC video/audio, WebSocket signaling. Canvas syncs across participants in real-time. BE Project @ MIT Thandavapura, VTU.
